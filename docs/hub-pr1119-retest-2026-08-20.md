## Findings

1. **Close-frame relay: fully verified.** Every socket teardown across all four
   scenarios ended in a clean close frame with a usable code (1000/1001/1013/
   4404). Nothing the UI has to special-case as a bare disconnect.
2. **The 45 s no-endpoints hold did not reproduce** (3 post-exit redials: 111 ms,
   13 ms, 5 ms). The endpoint reap won the race every time and the new
   refused→1013 mapping made it clean. The dial-timeout suggestion drops from
   "residual bug" to nice-to-have hardening for the endpoint-lag race.
3. **Log-noise nit for Jeff:** every relay teardown logs
   `websocket: close sent` with a stack trace from `sendClose` — the second
   goroutine's duplicate close attempt. Expected on every normal teardown, so
   worth ignoring `ErrCloseSent` (or demoting below error) to keep real relay
   errors visible.
4. **1011 branch and the 1006→1001 filter weren't black-box reachable.** Both
   kill flavors surfaced clean closes before the abnormal path could fire
   (in-pod teardown emitted close frames; SIGKILL's kernel FIN raced the UI's
   own reconnect close). Not a defect — just noting the branches remain
   code-review-verified rather than live-verified.
5. **AC-side observation (not hub):** force-deleting a sandbox pod resurrects
   it and the run restarts from scratch on the new pod — second grounding
   commit, doubled model usage, transcript restarts mid-view. Graceful delete
   ends the run as Failed instead. Worth deciding upstream whether vanished-pod
   resurrection is intended for agent runs (agentic-controller, not #1119).
6. **Harness token self-revocation still 403s** — every run teardown logs
   `POST /auth/tokens/{id}/revoke → 403 "Required scope not granted:
   tokens:POST"`. The addon/harness role still lacks the `tokens` scope — the
   open question deliberately left out of the original seed PR, now visible in
   the wild on every run. Minted run tokens are never revoked (they age out on
   TTL instead).
7. Known-issue confirmations: UI session died at ~5 min (OIDC refresh — ui#3545
   fix pending); hub still logs `Tackle CR not found` noise on this
   operator-less install; architect get-only on agents/gateways unchanged (no
   seed changes in the delta).
